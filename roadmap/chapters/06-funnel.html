動線設計編：
Threads → LINE → BASE をなめらかにつなぐ

Chapter 3〜5で 3つの箱 を作りました。
ここで、それらを 1本の道 として接続します。動線がつながった瞬間、初めて0→1が現実になります。

動線の全体像（必ず暗記してください）

①Threads
出会い
→
②LINE
関係づくり
→
③BASE
販売
→
④LINE
継続関係

※「販売後にLINEに戻ってくる動線」がリピーター化の鍵

初心者ママがやりがちな失敗：
❌ Threadsに直接BASEのURLを貼る
✅ Threads → LINE → BASE の 必ず3段 を踏ませる

理由：初対面の人はいきなり買いません。LINEで関係を温めてから案内するほうが 5〜10倍 売れます。

Step 1：Threads → LINE 誘導の最適化

3つの動線出口を作る

Threadsから公式LINEへの動線は、3箇所 に作ります。

  1. プロフィールのリンク欄（常設・最も流入が多い）
  2. 固定投稿（自己紹介＋特典案内を1つ作って固定）
  3. 誘導型投稿（週2本）（Chapter 5のテンプレ参照）

▶︎LINE登録はプロフィールのリンクから

明日も、ここで会えますように🍃
📌 リンクは「lit.link」で1つに

Threadsのリンク欄は1つしか入りません。複数案内したい場合は lit.link（無料・日本製）でリンクまとめページを作る。
構成：① 公式LINE（最上部・最目立つ位置）　② BASEショップ　③ プロフ詳細
※lit.link自体は 後回しでもOK。最初は公式LINE単独で十分。

Step 2：LINE → BASE 誘導の最適化

公式LINEに登録してくれた人を、どのタイミングで・どう商品案内につなげるか。
ここを設計しないと、登録者ばかり増えて売上ゼロになります。

LINEステップ配信プラン（最初の2週間）

登録後配信内容狙い
0日（即時）あいさつメッセージ＋特典案内第一印象＋特典DLしてもらう
1日後「特典の使い方」フォローメッセージ放置防止・実際に読んでもらう
3日後あなたの経験ストーリー（共感）「この人も同じだった」と思ってもらう
7日後役立ち情報＋ペルソナの本音アンケート悩みを言語化してもらう
10日後商品の予告（先行案内日を伝える）期待を作る
14日後商品先行案内＋クーポン配信初販売トライ
📌 ステップ配信は無料プランでも可能

LINE公式アカウント無料プランは月200通まで配信可能（友だち数が増えると有料プラン推奨）。
最初の数十人までは無料プランで十分。「ステップ配信」機能 で時間差配信を自動化できる。

Step 3：BASE → LINE 戻り動線（リピーター化）

ここが、初心者ママのほとんどが見落とす設計。
BASEで購入したお客様を、LINEに戻す ことで、2回目以降の販売が劇的にラクになります。

戻り動線を3箇所に設置

  1. 商品PDFの最終ページ：QRコード＋「ご質問・追加特典はこちらの公式LINEへ」
  2. BASEの購入完了メール（自動）：BASEの設定でメール本文に公式LINEのURLを追加
  3. 商品ページの本文末尾：「ご購入特典として、公式LINE登録で○○をプレゼント」

📌 「購入済」キーワードでタグ自動付与

Chapter 3で作った #購入済 タグを、ここで自動付与する設定にします。
購入済タグの人には、次回の新商品案内・上位商品の案内ができる VIPリスト として活用。

動線が「なめらか」かをチェックする方法

4日間の最後（Day 21）に、自分でテストカスタマー体験 をします。

🧪 動線テストチェック
  • Threadsを別アカウント or 友達のスマホで開いて、自分のプロフを見る
  • プロフから公式LINEに飛べるか（タップしやすい？）
  • 友だち追加→あいさつメッセージが届くか
  • 「特典」と送って自動応答PDFが届くか
  • PDFをダウンロードできるか・最終ページのQRが読めるか
  • BASEのショップURLにLINEから飛べるか
  • BASEで購入したら、購入完了メールにLINEのURLがあるか
  • 商品PDFの最終ページから公式LINEに戻れるか
💭 詰まりポイント

「動線テスト、何が正解かわからない」

長子長女さんは「ちゃんとできてるか不安」が出やすい。
正解は 「自分が初めての人になりきって、迷わずたどれるか」。
どこか1箇所でも「あれ？」と思ったら、そこをお客様も詰まる場所。

家族・友人・ママ友1人だけに「これ試してフィードバックほしい」と頼む。
身内の冷静な視線が、最大のデバッグツール。1人だけでいい、頼っていい。
