# UTAGE実装ガイド｜0→1ロードマップブック

このフォルダ（`utage/`）の中身を、UTAGEに **コピペで貼るだけ** で、
ロードマップブックを「有料商品＋会員サイト」として配信できる状態にします。

---

## 📁 ファイル構成

```
utage/
├── README.md            ← このファイル（実装手順）
├── utage-header.html    ← UTAGE全体に1回だけ貼るCSS（共通スタイル）
├── sales-lp.html        ← 販売LP（商品紹介ページ）
├── thanks.html          ← サンクスページ（決済完了後）
└── lessons/
    ├── 00-prologue.html ← Chapter 00：はじめに
    ├── 01-mindset.html  ← Chapter 01：マインドセット編
    ├── 02-product.html  ← Chapter 02：商品設計編
    ├── 03-line.html     ← Chapter 03：公式LINE構築編
    ├── 04-base.html     ← Chapter 04：BASE構築編
    ├── 05-threads.html  ← Chapter 05：Threads集客編
    ├── 06-funnel.html   ← Chapter 06：動線設計編
    ├── 07-launch.html   ← Chapter 07：初販売編
    └── 08-stuck.html    ← Chapter 08：詰まったとき辞典
```

各ファイルは **UTAGEのカスタムHTMLブロック** にそのまま貼り付け可能なフラグメント形式です。

## 🚀 全体の実装フロー（所要時間：約2〜3時間）

### ステップ1. 共通スタイルを設定（5分）

`utage-header.html` の中身ぜんぶを、UTAGEの管理画面で1回だけ貼り付けます。

**貼り付け先（プランによって名称が異なります）：**
- ヘッダーカスタム
- カスタムHTML（ヘッダー）
- 共通ヘッダースクリプト
- いずれかにある「全ページに適用されるカスタムHTML欄」

これで、9章すべてのレッスン・LP・サンクスページに同じデザインが適用されます。

> ⚠️ **CSSは `.utage-embed` クラスにスコープ済みなので、UTAGEの他のページや既存テンプレには影響しません。**

---

### ステップ2. 商品（ファネル）を作成（30分）

UTAGEの管理画面で：

1. **「ファネル」 → 「新規作成」** を押す
2. **ファネル名**：「副業ママ0→1ロードマップブック」など
3. **ファネルの構成**：以下の3ページを作成
   - **販売ページ**（sales-lp.htmlを貼る）
   - **申込フォーム**（UTAGEのデフォルトフォームでOK）
   - **サンクスページ**（thanks.htmlを貼る）
4. **決済設定**：
   - 商品名：副業ママ0→1ロードマップブック
   - 価格：19,800円（推奨）／ 任意の価格に変更可
   - 決済方法：クレジットカード・銀行振込・コンビニ決済
5. **販売ページ**にアクセスして、表示確認

---

### ステップ3. 各ページにHTMLを貼る（20分）

#### 販売ページ
1. 「販売ページを編集」
2. 「カスタムHTMLブロック」を追加
3. `sales-lp.html` のHTMLぜんぶをコピペ
4. ボタンの遷移先 `#APPLY` を、UTAGEの **申込フォームURL** に置換
5. プレビューで確認

#### サンクスページ
1. 「サンクスページを編集」
2. 「カスタムHTMLブロック」を追加
3. `thanks.html` のHTMLぜんぶをコピペ
4. プレースホルダを置換：
   - `#LINE_FRIEND_URL` → 公式LINEの友だち追加URL
   - `#MEMBER_SITE_URL` → 会員サイトのURL
5. プレビューで確認

---

### ステップ4. 会員サイト（コーススクール）を作成（30分）

UTAGEの管理画面で：

1. **「会員サイト」 → 「新規コース作成」**
2. **コース名**：「副業ママ0→1ロードマップブック」
3. **コース説明**：販売LPの冒頭を流用
4. **コースカバー画像**：Canvaで作成 or 任意の画像

5. **レッスン（章）を9つ作成**：

| 順番 | レッスン名 | 貼るファイル |
|---|---|---|
| 1 | はじめに：詰まる7つの罠と地図 | `lessons/00-prologue.html` |
| 2 | Chapter 01：マインドセット編 | `lessons/01-mindset.html` |
| 3 | Chapter 02：商品設計編 | `lessons/02-product.html` |
| 4 | Chapter 03：公式LINE構築編 | `lessons/03-line.html` |
| 5 | Chapter 04：BASE構築編 | `lessons/04-base.html` |
| 6 | Chapter 05：Threads集客編 | `lessons/05-threads.html` |
| 7 | Chapter 06：動線設計編 | `lessons/06-funnel.html` |
| 8 | Chapter 07：初販売編 | `lessons/07-launch.html` |
| 9 | Chapter 08：詰まったとき辞典（お守り） | `lessons/08-stuck.html` |

各レッスンの編集画面で：
- 「カスタムHTMLブロック」を追加
- 該当するHTMLファイルの中身ぜんぶをコピペ
- 保存

---

### ステップ5. 決済→会員サイト招待を自動化（20分）

UTAGEの「自動化（ステップシナリオ）」で設定：

1. **トリガー**：商品「副業ママ0→1ロードマップブック」の決済完了
2. **アクション①**：会員サイトのコース「0→1ロードマップブック」に自動登録
3. **アクション②**：購入完了メールを送信（会員サイトURLとログイン情報を含む）
4. **アクション③（任意）**：公式LINE連携でタグ「#購入済」を自動付与

---

### ステップ6. 動作テスト（30分）

⚠️ **必ず公開前にやってください。**

1. **テスト購入** をする（無料クーポンコード or 0円商品で）
2. 申込フォームに入力 → 決済完了
3. サンクスページが表示される
4. 会員サイトの招待メールが届く
5. メール内のリンクから会員サイトにログインできる
6. 9章すべてのレッスンが表示される
7. 各レッスンが正しいデザインで読める

## 🎨 デザインのカスタマイズ

CSS変数を変えるだけで、配色を一括変更できます。
`utage-header.html` の最初の `.utage-embed { ... }` ブロック内で：

```css
--c-accent: #C28E6E;          /* メインカラー（くすみテラコッタ） */
--c-pink: #E8B7B0;            /* アクセントピンク */
--c-mint: #A8C3B5;            /* 抜け方ボックス */
--c-bg: #FBF7F2;              /* 背景色 */
```

ご自身のブランドカラーに合わせて変更してください。

## 🔧 困ったとき

### 「貼ったのに表示が崩れる」
- `utage-header.html` の貼り忘れ。ステップ1を再確認。
- 既存のUTAGEテンプレが強いCSSを当てている可能性。`.utage-embed` クラスへの上書きが効いているか開発者ツールで確認。

### 「フォントがゴシックに戻る」
- Google Fontsの読み込み失敗。`utage-header.html` の `<link>` タグが正しく貼られているか確認。

### 「カスタムHTMLブロックが見当たらない」
- UTAGEのプランによっては「フリーHTML」「コードブロック」など名称が違います。それで貼ってください。

### 「カスタムHTMLが使えないプラン」
- 各HTMLファイルをご自身のサーバー or Cloudflare Pages等にアップロードし、UTAGEから **iframe埋め込み** で表示する方法もあります。
